📸 Photo Migration Checklist

Sats for Trash — outings + spots, tap through in order

Per photo:
  1. Tap Open → long-press the image → Download
  2. Open it in Squoosh → resize ~1200px, quality 75 → export
  3. In Files app, rename the exported file to the filename shown below
  4. Move it into one local folder (e.g. sats4trash-upload/)
  5. Tick the box — it's saved on this device so you can stop and resume anytime
When a section is fully ticked, batch-upload that folder's contents to the matching GitHub folder in one go.
